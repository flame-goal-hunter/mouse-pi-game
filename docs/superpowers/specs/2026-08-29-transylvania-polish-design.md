# Замок Теней — полировка, сюжет, управление, производительность

**Дата:** 2026-08-29 · **Ветка:** network_mode · **Статус:** утверждено пользователем (тон, стиль, сюжет, объём)

## 0. Решения, принятые с пользователем

| Вопрос | Решение |
|---|---|
| Масштаб | Полировка + сюжет. Top-down геймплей (ключ → выход, 5 этажей) сохраняется |
| Тон | Весело-жуткий («Монстры на каникулах»): темно и таинственно, монстры смешные |
| Сюжет | «Бабушкин пирог» |
| Визуал | «Тёплая готика»: фиолетовый камень + янтарный свет факелов + золото меню (#e8b54a) |
| Меню | Чиним и рестайлим все три: главное меню, меню Замка Теней, внутриигровой HUD |
| Персонажи | Спрайты дочки — неприкосновенная основа. Врагам-перекраскам рисуем костюмы в том же стиле |
| Управление | Полный мобильный набор кнопок + бест-практис (буферизация, вибрация, aim assist) |
| Реиграбельность | Процедурная генерация всех 5 этажей существующим генератором |

**Не трогаем:** GameScene / мультиплеер / снежки, пайплайн ice-arena (CLAUDE.md), Capacitor/Gradle конфиг, сетевой код index.html (PeerJS).

## 1. Запуск и главное меню (index.html)

Проблема: при входе в Трансильванию `currentGameMode='transylvania'`, `gameRunning=true` — старый canvas-геймлуп (update+draw) молотит на 60 FPS за iframe всё время игры. Плюс тройной запуск: index → iframe c Phaser → редирект на transylvania-menu.html → снова навигация → второй запуск Phaser.

**Дизайн:**
- `startTransylvaniaPreview()` грузит iframe **сразу** на `transylvania-menu.html` (без Phaser-редиректа). Редирект-ветку в BootScene оставляем как fallback.
- Глобальный гейт геймлупа: пока `phaserRunning === true`, `gameLoop()` не вызывает `update()/draw()` вообще (rAF продолжает тикать вхолостую или останавливается и перезапускается по `closePhaserSnowball`).
- `draw()`/`update()` получают явную ветку для `currentGameMode === 'transylvania'` (ничего не рисовать).
- Точечная косметика главного меню: единые радиусы/тени кнопок режимов, без переписывания разметки.

## 2. Меню Замка Теней (transylvania-menu.html/css/js)

- Рестайл под «Тёплую готику»: каменная кладка фоном (CSS-градиенты), 2-3 тёплых пятна света, силуэт замка. Никакого `backdrop-filter: blur` (лагает в Android WebView) — заменить на затемнение `rgba`.
- Анимации только `transform`/`opacity` (композитор), максимум 2 одновременных: покачивание Пи (3s ease-in-out) + мерцание пламени. `prefers-reduced-motion` уважаем.
- Google Fonts → локальный WOFF2 Nunito в `www/assets/fonts/` (офлайн-запуск без сетевой задержки; убрать preconnect).
- При старте забега — оверлей «Замок просыпается…» (мгновенный, CSS) до навигации, чтобы скрыть загрузку Phaser.
- Модалки лавки/кодекса: сохраняем структуру, обновляем палитру под готику.

## 3. Производительность DungeonScene

Приоритетный список (по убыванию вреда):

1. **Запечь статику уровня.** `drawCarvedFloor` (~7000 команд) и `wallGfx` (~3500 команд) рисуются в мировую RenderTexture **один раз** в `buildWorld`, исходные Graphics уничтожаются. Кадр рисует 1-2 квада вместо ~24k треугольников.
2. **Свет.** Вместо RT 2600×1900 (20 МБ VRAM) + инвертированный BitmapMask на весь мир — RT размером с камеру (`cam.width×cam.height`, scrollFactor 0), обновление каждый кадр (60 Гц — фонарик перестанет дёргаться). Композиция: тёмный прямоугольник + ERASE-круги источников света.
3. **Слить Graphics.** ~70-85 пропов + ~45-85 факелов → пропы запекаются в общий слой/текстуры при создании; пламя всех видимых факелов — **один** общий Graphics с одним clear() на кадр.
4. **Пулы.** `showFloatingText` (Text) и `poofAt` (13 объектов + 13 твинов за вызов) → пул из ~24 Text и ~64 кружков, без create/destroy в бою.
5. **Твины пикапов.** 60-120 вечных yoyo-твинов сыра/сердец/ключа → ручная анимация (sin) внутри существующего культ-цикла видимости.
6. **Аллокации в горячем цикле:** `enemies.filter` → swap-remove; `queryWallsAround` → переиспользуемый scratch-массив; `buildDijkstraMap` → переиспользуемые Int32Array; хойст замыкания `exitBtnArea`; литерал эмодзи-таблицы из `updateHUD` → константа.
7. **Баг слоу-мо:** `_hitStop` с `setTimeout` → `this.time.delayedCall` + сброс `timeScale` в `shutdown`.
8. **Дисциплина update():** `updateCrosshair`/`updateCompass`/`updateDashButton` — только в `state==='play'` и по dirty-флагу.
9. Камера-шейк: длительности/амплитуды сохраняем, но `roundPixels` оставляем — проверить визуально после запекания пола.

**Целевые метрики:** стабильные 60 fps в бою на среднем Android; ноль created-per-frame объектов в профиле; VRAM света ≤ 4 МБ.

## 4. Визуальный стиль уровня — «Тёплая готика»

- **Пол:** плиты 80px (2×2 нав-клетки), два близких тона фиолетового камня, **без 1px-сетки**; 4-6% клеток — трещинка/камешек. Запекается (п. 3.1).
- **Стены:** кладка с тёмным верхним кантом и тёплой золотой линией по кромке.
- **Дорисовать 11 недостающих пропов** (сейчас все → грибы): bookshelf, skull, chain, redCarpet, moonflower, glowpod, hedge_tuft, lilypad + удалить/подключить мёртвые painters (candle, flower, vine, glass). Грибы остаются только в подземелье.
- **Эмодзи в мире → SVG:** сундук, реликварий, книга-отвлекалка, свеча/канделябр, спящий «💤» → простая SVG-иконка. Стиль — как у персонажей (толстая тёмная обводка, простые формы).
- **Биомы различаются светом и темнотой:** подземелье 0.78 (янтарь), библиотека 0.70 (тёплые свечи), кухня 0.60 (самая светлая, очаг), сад 0.74 (лунно-синие акценты из варианта B), тронный зал 0.82 (самый тёмный, золотые блики). Тона пола/стен — свои на биом (уже есть), убрать золотую сетку трона.
- **Единая таблица depth-констант** вместо ~40 магических значений (LAYER = { FLOOR:0, DECOR:50, PICKUP:100, ENEMY:150, PLAYER:200, FX:300, DARKNESS:700, UI:1000 }).

## 5. HUD

- Сетка от safe-area: **слева сверху** сердца + ключ; **центр сверху** сыр + комбо; **справа сверху** компас + пауза/выход. Статусная строка (крадусь/книги/тревога) — одна, под сердцами, элементы не пересекаются.
- Масштаб: `uiScale = clamp(min(W,H)/640, 0.8, 1.3)`, все размеры и шрифты через него. Проверка на 360×640.
- Починить наложения: suspicionMeter/label (обе в 28,70), keyIcon vs cheeseText.
- Все HUD-иконки — SVG (без эмодзи).
- Окна выбора апгрейда/реликвии, лавка и оверлеи побед/поражений: переверстать от размеров экрана (карточки ≥ 96px высоты, скролл при нехватке места, кнопки ≥ 48px).

## 6. Сюжет «Бабушкин пирог»

Принципы (бест-практис детских игровых сюжетов): реплики ≤ 90 символов, максимум 2 подряд, всё скипается тапом; юмор через повтор-тройку; твист заложен заранее (правило «покажи до развязки»); никакого текста без нужды — история рассказывается декором и светом там, где можно.

**Завязка (интро, 3 кадра-виньетки, тап = дальше, скип-кнопка):**
1. Домик, бабушка ставит пирог на окно. Пи принюхивается.
2. Огромная тень уносит бабушку ВМЕСТЕ с пирогом. Падает записка.
3. Пи с фонариком у ворот замка. «Держись, бабушка!»

**Этажи — владения «начальников» (реплика на входе + шутка при победе/выходе):**

| Этаж | Биом | Начальник | Вход | Выход |
|---|---|---|---|---|
| 1 | Подземелье | Страж (зомби в шлеме) | «Стой! Кто идёт?.. Мышь? Всё равно стой!» | «Прошёл... А я и не выспался.» |
| 2 | Библиотека | Библиотекарь (зомби с очками) | «Тс-с-с! Книги спят!» | «Забирай ключ, только ТИХО.» |
| 3 | Кухня | Шеф-повар (кот в колпаке) | «Мышь?! На МОЕЙ кухне?!» | «Ладно... держи ключ. И рецепт спроси у бабушки!» |
| 4 | Сад | Львиный зев (слизень с лепестками) | «Я цветочек. Хищный цветочек!» | «Полей меня перед уходом, а?» |
| 5 | Тронный зал | Король Теней | «Пирог МОЙ! И бабушка тоже!» | — (финал) |

**Крошки-твист — записки бабушки** (1-2 на этаж, собираются, копятся в кодексе; заранее готовят развязку):
- «Меня несут куда-то вниз. Пирог держу крепко!»
- «Король чихнул. Я сказала "будь здоров". Он ОЧЕНЬ удивился.»
- «Спросила, когда у него день рождения. Он не помнит...»
- «Кажется, ему никто никогда не пёк пирога.»

**Развязка:** после боя Король (сдувшись): «Я... просто хотел попробовать пирог. У меня не было дня рождения. Ни одного.» Бабушка (выходя из клетки): «Так бы и сказал! Ну-ка, ставь чайник.»

**Финал — сцена чаепития:** длинный стол, бабушка режет пирог, вокруг ВСЕ монстры игры (страж, библиотекарь, шеф, зев, зомби, кот, слизень, призрак, скелет, мимик с чашкой на языке), Король в бумажном колпаке «С днём рождения». Пи рядом с бабушкой. Тёплый свет. Титр: «Конец... до следующего пирога».

**Техника:** диалог-панель — один запечённый gothic-panel + Text, тап в любом месте = следующая реплика; интро/финал — статичные композиции из существующих SVG + твины появления. Начальник этажа — гарантированный спавн своего врага у комнаты с ключом, триггер-зона реплики. Записки — новый пикап-SVG «записка», хранение в ProgressStore (кодекс). Эндлесс-режим получает рамку «Сны о замке» (одна строка при старте, без сцен).

## 7. Персонажи и костюмы

- Спрайты дочки (pi, zombie, cat, slime, bat, ghost, skeleton, mimic, grandma) — **без изменений форм и черт**.
- Новые SVG-варианты (на базе существующих, те же пропорции и стиль обводки): **шеф** = cat + колпак/половник, **библиотекарь** = zombie + очки/книга под мышкой, **страж** = zombie + шлем/щит, **босс** = zombie ×1.6 + корона теней + мантия, **львиный зев** = slime + лепестки. Тинты-перекраски удаляются.
- Единая подача: тень-эллипс под всеми (уже есть у игрока — распространить), белая вспышка при уроне (есть), лёгкий squash при приземлении/ударе (есть — унифицировать параметры).

## 8. Управление (мобайл)

- **Новая кнопка «Красться»** — тумблер над левым стиком (зона большого пальца левой руки), ≥ 56px, чёткое состояние: нажат = кольцо + иконка «тихие лапки», у игрока полупрозрачность/сжатие (есть).
- **Новая кнопка «Книга»** — рядом с рывком, показывает остаток книг цифрой-бейджем; скрыта, пока книг 0.
- **Рывок** — переносится ниже/левее (внутренняя дуга правого большого пальца), не над зоной прицела; расстояние до зоны спавна aim-стика ≥ 24px.
- **Буферизация ввода:** нажатие рывка за ≤ 150 мс до конца кулдауна — запоминается и срабатывает (forgiveness).
- **Aim assist:** мягкое домагничивание прицела ±10° к ближайшему врагу в секторе до 400px — только для тач-стика (не для мыши).
- **Вибрация** через `navigator.vibrate` (с проверкой поддержки): 10 мс рывок, 25 мс получение урона, 15 мс ключ/реликвия, паттерн [30,50,30] босс повержен. Тумблер «вибрация» в настройках лавки не нужен — включена всегда, интенсивности минимальные.
- SVG-иконки на всех кнопках (💨🥧✥ → отрисованные), подписи «ХОДЬБА/ПРИЦЕЛ» показываются только в первом забеге (флаг в ProgressStore) и гаснут через 8 с.
- Убрать мёртвый код `isTouchUiPointer` (ветка `p.x < half || p.x >= half`).
- Кнопки и стики не пересекаются на 360×640 и на планшете; всё от safe-area.

## 9. Реиграбельность

- **Процедурные этажи 2-5:** существующий генератор (комнаты + MST + петли) параметризуется `biome.roomConfig` (уже есть в Biomes.js). Ручные планировки удаляются.
- **Гарантии на этаж:** стелс-комнаты по `stealthRoomsPerFloor`; комната начальника этажа возле ключа; сундук реликвии (с этажа 2); 1-3 сырные комнаты; ключ на расстоянии ≥ 60% максимума flow-field от спавна; выход достижим (проверка существующим Dijkstra, при провале — регенерация, максимум 3 попытки, затем фиксированный fallback-сид).
- **Сид пишется в лог** (`console.log`) для воспроизводимости багов.
- Состав врагов — по биомным весам (уже есть), плотность — существующий `enemyDensityMul` с лёгким ростом по главе.

## 10. Критерии приёмки

1. 60 fps в бою на телефоне пользователя (профиль до/после, chrome://inspect).
2. Меню Замка Теней открывается < 1 с из главного меню; забег стартует < 3 с.
3. За iframe ничего не обсчитывается (профиль index.html в фоне ~0% CPU).
4. HUD и кнопки помещаются и не пересекаются на 360×640.
5. Ни одного эмодзи в игровом мире и HUD (эмодзи допустимы только в HTML-меню).
6. Каждый биом отличим на скриншоте (палитра + свет + декор).
7. Стелс проходим на телефоне: можно красться и бросать книги без клавиатуры.
8. Два подряд забега истории дают разные планировки этажей 2-5.
9. Сюжет: интро, 5 реплик начальников, записки, развязка, чаепитие — всё скипается тапом.
10. Слоу-мо после рестарта сцены не залипает (фикс _hitStop).
