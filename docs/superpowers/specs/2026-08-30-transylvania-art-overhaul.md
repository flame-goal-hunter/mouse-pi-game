Дата: 2026-08-30. Дополняет `2026-08-29-transylvania-polish-design.md` (§4, §5, §2, §1 заменяются этим документом; §3 perf, §6 сюжет, §7 костюмы, §8 управление, §9–10 экономика остаются в силе и идут после).

## 1. Решения

| Вопрос | Решение |
|---|---|
| Персонажи | Рисунки дочки — неприкосновенная основа (`www/assets/characters/transylvania/*.svg`, 9 скинов). Улучшаем неразрушающе: единая толщина контура, тень и подача в игре, анимация, размеры |
| Окружение и UI | Рисую SVG-набор **в стиле персонажей**: контур `#1a1a1a`, радиальные градиенты, круглые силуэты, блик. Никаких пиксель-паков — они спорят с персонажами |
| Эмодзи | Ноль в игре и в меню (кроме HTML-заглушек до замены). Иконки — SVG из одного набора |
| Рендер | Канвас в физических пикселях (`min(DPR, 3)`), `antialias: true`, текстуры LINEAR, `roundPixels` |
| Звук | Kenney CC0 (`ui-audio`, `impact-sounds`, `rpg-audio`, `music-jingles`) скачиваются автоматически с kenney.nl; музыка-лупы — CC0 с OpenGameArt, если недоступно — улучшенный `ProceduralBgm` как запасной вариант |
| Меню | HTML-меню переверстать под ландшафт 360×640…915×412 через скил `frontend-design`; герои меню — мышонок и монстры дочки |
| Проверка | Каждая визуальная задача закрывается **скриншотом** через пайплайн (`memory: screenshot-pipeline`) + проверкой на телефоне |

**Не трогаем:** GameScene / мультиплеер / снежки, PeerJS-код `index.html`, пайплайн ice-arena, Capacitor/Gradle.

## 2. Стиль-гайд (выведен из персонажей)

- **Контур:** `#1a1a1a`, `stroke-linejoin/linecap: round`. Толщина относительно размера: персонажи 150–230px → 2.5–3px; тайлы 40–80px → 1.5–2px; иконки 64px → 3–4px (читаемость при уменьшении).
- **Заливка:** плоский цвет + радиальный градиент «свет сверху-слева» (светлее на 12–18%), один блик `#ffffff` opacity .4–.6, тень внутри opacity .15–.25.
- **Силуэты:** круглые, «кукольные», без острых углов кроме шипов/зубов.
- **Палитра биомов** — из `Biomes.js` (пол A/B, стены, тьма), акценты: золото `#e8b54a`, крем `#fff0d6`, сыр `#ffd24a`, кровь/опасность `#ff4a5c`, свет факела `#ffb347`→`#ff7a2a`, лунный свет сада `#bfd8ff`.
- **Свет:** тёплые факелы (амбер), холодная луна в саду, тьма по биому; персонаж всегда читается (halo).
- **Типографика (игра и меню):** Nunito 900 для заголовков/цифр, 700 для кнопок, 400/600 для текста; шрифт локально в `www/assets/fonts/` (без Google Fonts на критическом пути).
- **UI-кит:** панель 9-slice (тёмно-фиолетовое стекло `#1a0c2e` α.92, рамка `#e8b54a` 2px, скруглён. 18, угловые «гвозди»), кнопка (обычная/нажата/недоступна; primary — золотая, secondary — контурная), пилюля, карточка, полоса прогресса, иконки 64px. Целевые зоны ≥48dp.

## 3. Фазы (каждая — свой план, свой набор коммитов, скриншот-приёмка)

### A. Рендер-база и платформа
1. DPR: игровой размер = CSS×dpr (`Scale.NONE` + ручной `resize` на `window.resize`, дебаунс 200 мс, как сейчас), `cameras.main.setZoom(dpr)`; все фиксированные слои (HUD, тач-контролы, тьма `lightRT`, оверлеи) живут в контейнерах со смещением `((dpr−1)/2·cssW, (dpr−1)/2·cssH)` и координатами в CSS-пикселях; `pointer.x/dpr` в тач-коде; `lightRT` в CSS-размере (масштаб dpr). Kill-switch `?dpr=1`. Приёмка: скриншот DPR 2 — контуры и текст без мыла; fps на Pixel 9a не хуже.
2. `antialias: true` (+ `antialiasGL`), убрать ручной LINEAR-цикл. Приёмка: стики/кольца гладкие.
3. Лоадер по режиму: для `transylvania` — тёмная сцена, замок/луна, мышонок, полоса золотая, подсказка про стики (или без подсказки на тач).
4. Интро: HUD и стики скрыты до `play`; подсказка управления зависит от `IS_TOUCH`; кнопка «Начать» на UI-ките.
5. Шрифт: локальный Nunito + `document.fonts.ready` перед `new Phaser.Game`.

### B. Арт-кит уровня (SVG → текстуры, запекание в `worldRT` батчем)
- Пол: 2 плиты 80×80 на биом + накладки трещина/камешки 40×40 (тонируемые).
- Стены: 4 варианта клетки 40×40 (обычная / верхний кант / плинтус / оба) × 5 биомов; кладка 40px-периодична.
- Факел: бра 24×28 (origin низ, 4 поворота) + пламя 3 кадра 16×32 (спрайт-анимация вместо перерисовки эллипсов каждый кадр).
- Дверь выхода 80×110 + замок/открыт; лестница 72×80 + стрелка; сундук закрыт/открыт 48×48 (в паре с `mimic.svg`); урна реликвии; книга (запретная/брошенная); канделябр незажжён/зажжён; мешок муки; котёл на цепи; сердце (из `ui/heart.svg`); усилители (из `ui/*.svg`); клетка бабушки 128×160; трещина слабой стены 80×40.
- Пропсы: 16 SVG (шкаф, ковёр, череп, кость, горшок, мешок, книга, свеча, свиток, кубок, гриб, лунный цветок, светопод, куст, кувшинка, паутина); тарелка/нож/чернильница/лиана/цепь — выкинуть (≤16px, не читаются).
- Биом-тайлы: масло, лианы (с объектом для удаления — сейчас утечка `:5338-5348`), шипы, горячая сковорода 3 фазы.
- Свет: мягче края, тёплый тон, у персонажа halo; тьма читаемая на троне.
Приёмка: скриншот каждого из 5 биомов — «это нарисовано, а не сгенерировано»; ни одного Graphics-пропса; fps не хуже.

### C. Персонажи (подача, без перерисовки)
- Аудит SVG: одинаковая толщина контура и наличие блика; починить несостыковки минимальными правками атрибутов (не формы).
- В игре: единая «визуальная высота» врагов (шкала на тип), мягкая тень-эллипс под всеми, `_hitFlash` без потери тинта вариантов (`:4670-4682` — сейчас `clearTint` стирает окраску повара/библиотекаря/дракона), сплющивание при ударе/приземлении, «дыхание» в покое, поворот по направлению, смерть — «пуф» + исчезновение, появление — «поп».
- Мышонок: кадры ходьбы уже есть — добавить наклон в сторону движения (есть) и пыль под ногами при рывке.
Приёмка: ролик/скриншоты: покой, ход, удар, смерть — «живые».

### D. UI-кит и внутриигровые окна (поглощает план 2c)
- 9-slice панель/кнопки/карточки как текстуры; `Phaser.GameObjects.NineSlice` (3.60+).
- Переверстать: интро, выбор апгрейда, выбор реликвии, лавка в забеге, победа/поражение, всплывающие тексты — без эмодзи, иконки SVG (реликвии 16 шт., апгрейды 8, биомы 5), карточки ≥96px, кнопки ≥48px, скролл при нехватке места.
- Переходы: затемнение между этажами и в меню (fade 250 мс), кнопки — нажатие 0.96 + звук.

### E. Меню (скил `frontend-design`)
- `index.html`: гейт `draw()`/непрозрачная модалка, табы в один ряд, кнопка внутри карточки; карточка «Замок Теней» ведёт сразу в меню замка.
- `transylvania-menu`: ландшафт — две колонки (герои слева: мышонок + летучая мышь/призрак/скелет «выглядывают», карточки и кнопки справа), портрет — колонка; луна и туман — фоновые слои с фиксированными отступами; `(orientation)` медиазапросы; без `backdrop-filter`; локальный Nunito; лавка и кодекс — на SVG-иконках, скины с превью из SVG, кодекс с силуэтами врагов вместо «???».
Приёмка: скриншоты 360×640, 640×360, 915×412 — ничего не наезжает, всё влезает без скролла в ландшафте (кроме модалок).

### F. Звук
- Карта `SoundKeys` → файлы Kenney (клики, подбор, удары, взрывы, шаги, «пуф»), нормализация громкости, категория UI/SFX/BGM, дакинг музыки при паузе/оверлеях.
- Музыка: 2 лупа (обычный этаж, босс) + джингл победы/поражения.
Приёмка: ни одного осциллятора в проде; громкости выровнены.

### G. Juice и переходы
Вспышка урона у края экрана, «поп» подбора сыра с полётом к счётчику, тряска сдержанная, hit-stop оставляем, пыль при рывке, искры факелов, дым, летающие частицы биома — всё через пулы.

## 4. Критерии приёмки оверхола
1. Скриншот уровня на DPR 2 не отличим по чёткости от нативной игры (контуры 1–2px чёткие).
2. Ни одного Graphics-примитива в статичном окружении; ни одного эмодзи в игре и меню.
3. Все три меню помещаются на 360×640 / 640×360 / 915×412 без наездов.
4. 60 fps на Pixel 9a в бою (не хуже фазы 1).
5. Звук: файлы CC0, музыка зациклена без щелчка.
6. Персонажи дочки визуально не изменены (формы/цвета), но «живые» и в едином масштабе.
