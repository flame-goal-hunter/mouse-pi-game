# Transylvania Phase B — Level Art Kit Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The level is drawn from real art — floor and walls as a Phaser Tilemap built from the generated per-biome SVG tilesets, props/torches/doors/chests/biome tiles/badges as SVG sprites — with no Graphics painters, no `worldRT` bake and no emoji in the world (spec `docs/superpowers/specs/2026-08-30-transylvania-art-overhaul.md` §3.B, §4 items 1-2).

**Architecture:** The assets already exist (commit "assets: level art kit"): `www/assets/tiles/<biome>.svg` (16 tiles × 40 px in one row, generated by `tools/gen_tiles.py` from `Biomes.js` palettes — indices documented in the script header) and `www/assets/world/*.svg` (props, objects, biome tiles, badges; the file's `viewBox` = its CSS-px size). Under the Phase A device-pixel canvas (`this.dpr`, camera zoom = dpr) every world texture is loaded at `viewBox × dpr` and displayed at `scale = 1/dpr`, so it is crisp. Floor/walls: `this.make.tilemap` with tile size `tilePx = round(40·dpr)`, three blank layers (`floor` −100, `detail` −95, `walls` −40) scaled by `40/tilePx`, filled from `navGrid` with the same plate-parity / neighbour rules the Graphics code used; weak walls get a `cracks` layer (−39) with per-tile alpha tweens. Decor is `add.image` at `LAYER.DECOR` (−50) — under the wall layer, restoring the 2a layering. Torch flames are a 3-frame sprite animation instead of a per-frame Graphics redraw.

**Tech Stack:** Phaser **3.70** (CDN; node_modules 3.90 — Tilemap/Texture APIs unchanged: `make.tilemap({tileWidth,tileHeight,width,height})`, `map.addTilesetImage(name, key, tw, th, margin, spacing)`, `map.createBlankLayer(name, tileset, x, y)`, `layer.putTilesAt(2dArray, 0, 0)`, `layer.putTileAt(idx, x, y)`, `layer.removeTileAt(x, y)`, `layer.getTileAt(x, y).alpha`, `Texture.add(name, sourceIndex, x, y, w, h)`, `anims.create`).

```js
    // Floor + walls as a Tilemap built from the biome tileset (see tools/gen_tiles.py for indices)
    buildTilemap() {
        const grid = this.navGrid, tp = this.tilePx;
        const map = this.make.tilemap({ tileWidth: tp, tileHeight: tp, width: NAV_W, height: NAV_H });
        const tileset = map.addTilesetImage('tiles', 'tiles_' + this.biome.id, tp, tp, 0, 0);
        const sc = NAV_CELL / tp;
        const mk = (name, depth) => map.createBlankLayer(name, tileset, 0, 0).setDepth(depth).setScale(sc);
        this.map = map;
        this.floorLayer = mk('floor', LAYER.WORLD);
        this.detailLayer = mk('detail', LAYER.WORLD + 5);
        this.wallLayer = mk('walls', LAYER.WALL_TILES);
        this.crackLayer = mk('cracks', LAYER.WALL_TILES + 1);
        const floor = [], detail = [], walls = [];
        for (let r = 0; r < NAV_H; r++) {
            const fr = [], dr = [], wr = [];
            for (let c = 0; c < NAV_W; c++) {
                if (grid[r][c] === 'floor') {
                    fr.push(this.plateTile(r, c));
                    const roll = Math.random();
                    dr.push(roll < 0.04 ? TILE.CRACK : roll < 0.06 ? TILE.PEBBLES : -1);
                    wr.push(-1);
                } else if (grid[r][c] === 'wall' && this.isBorderWall(r, c)) {
                    fr.push(-1); dr.push(-1);
                    wr.push(this.wallTile(r, c));
                } else { fr.push(-1); dr.push(-1); wr.push(-1); }
            }
            floor.push(fr); detail.push(dr); walls.push(wr);
        }
        this.floorLayer.putTilesAt(floor, 0, 0);
        this.detailLayer.putTilesAt(detail, 0, 0);
        this.wallLayer.putTilesAt(walls, 0, 0);
    }
    plateTile(r, c) {
        return (((r >> 1) + (c >> 1)) & 1 ? TILE.PLATE_B : TILE.PLATE_A) + (r & 1) * 2 + (c & 1);
    }
    wallTile(r, c) {
        const grid = this.navGrid;
        const wallAbove = grid[r - 1]?.[c] === 'wall' && this.isBorderWall(r - 1, c);
        const floorBelow = grid[r + 1]?.[c] === 'floor';
        return TILE.WALL + (wallAbove ? 0 : 1) + (floorBelow ? 2 : 0);
    }
```
